# Resumen del Conjunto de Datos

Esta base de datos recopila los indicadores económicos clave y los principales factores influyentes en la economía de Colombia durante el período 2024-2025. Los datos se basan en información obtenida de Perplexity.ai y sus fuentes citadas, que incluyen BBVA Research, Trading Economics, CEIC Data, Deloitte, Itau, Rystad Energy, QCIntel, The Global Economy, Medellin Advisors y ExchangeRates.

El conjunto de datos incluye variables como el crecimiento del PIB, inflación, desempleo, producción de petróleo, tipo de cambio, pobreza, reservas, deuda pública, balanza comercial, remesas, inversión extranjera directa y déficit fiscal. Además, analiza factores como las políticas del gobierno de Petro, el conflicto armado, la economía del narcotráfico y las relaciones comerciales con EE.UU.
