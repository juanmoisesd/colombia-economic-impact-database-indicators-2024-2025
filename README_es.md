# Base de Datos del Impacto Económico de Colombia 2024-2025: Indicadores Clave y Factores Influyentes

Parte de la Colección de Investigación Abierta de Juan Moisés de la Serna Tuya — ORCID: 0000-0002-8401-8018

## Resumen

Base de datos que compila indicadores económicos clave y los principales factores influyentes en la economía de Colombia durante 2024-2025.

## Descripción

Este conjunto de datos incluye: tasa de crecimiento del PIB, tasa de inflación, tasa de desempleo, producción de petróleo (bpd), tipo de cambio oficial (COP/USD), tasa de pobreza de los hogares, reservas de divisas, deuda pública (% del PIB), balanza comercial, remesas, inversión extranjera directa (IED) y déficit fiscal.
